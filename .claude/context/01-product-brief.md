# Product Brief

## What is this project?

The adamdanielbest design system is the foundation for a fully functioning portfolio website. It exists to make the site consistent, maintainable, and easy to update — so content, visual direction, and structure can be refined without rebuilding from scratch.

The project is also a case study in itself, demonstrating an AI-assisted design system workflow using Figma and Claude Code as core tools.

## Who is it for?

**Primary consumer:** Adam (sole author and user of the system).

**End audience:** Hiring managers and recruiters evaluating Adam for senior product design roles and contract work.

## What does it need to achieve?

1. A fully functioning portfolio website — showcasing work, case studies, and skills to attract the right roles
2. A complete, production-quality design system:
   - Tokens fully synced from Figma to CSS via a Figma → GitHub pipeline
   - Components documented in both Figma (style guide sheets) and code (HTML/CSS guideline pages)
3. A demonstrable, repeatable workflow using Figma + Claude Code as a case study

## Content

Existing portfolio and case studies are live. Content needs to be refined and repositioned against industry best practices for the target roles — not rebuilt from scratch.

## Measure of success

- Portfolio site live and attracting interview conversations
- Design system tokens, components, and pipeline fully operational
- Case study documenting the process ready to present

## Timeline

Target: live by November 2026.
